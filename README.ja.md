# Transformers.js Gemma 4 Browser Assistant（日本語版）

[English](./README.md)

このリポジトリは [nico-martin/gemma4-browser-extension](https://github.com/nico-martin/gemma4-browser-extension) のフォークであり、個人での検証・改修用途として運用しています。

## この拡張機能について

WebGPU と Transformers.js を使って、ブラウザ内で完全に動作するオンデバイスAIアシスタントです。  
この Chrome 拡張機能は、自然言語の指示を理解し、専用ツール群を通じてブラウザ操作を支援します。

すべての処理はローカルデバイス上で完結し、外部サーバーへデータを送信しません。プライバシーを維持したまま利用できます。

### できること

AIエージェントは複数のツールにアクセスでき、ブラウザの操作やナビゲーションを支援します。

#### タブ管理

自然言語で以下のタブ操作が可能です。

- **get_open_tabs**: 開いているタブをタイトル、URL、説明付きで一覧表示
- **go_to_tab**: タブIDを指定して目的のタブへ切り替え
- **open_url**: URLを新規に開く（バックグラウンド/フォアグラウンド対応）
- **close_tab**: 指定したタブを閉じる

#### Webサイト操作（RAG）

拡張機能は Retrieval-Augmented Generation を使って、ページ内容の理解と操作を行います。

- **ask_website**: 現在のページから意味的に関連する情報を検索・抽出。コンテンツスクリプトが見出し、段落、リストなどの構造化データを抽出し、all-MiniLM-L6-v2 で埋め込みを生成したうえで、クエリに最も関連するセクションを返します。
- **highlight_website_element**: ページ内の要素を視覚的にハイライト。関連箇所へスクロールして注目できるようにします。

#### 履歴ベクターデータベース

意味検索可能な閲覧履歴データベースを保持します。

- **find_history**: 完全一致キーワードではなく自然言語で履歴検索。ページタイトル、説明、URLのベクトル埋め込みを IndexedDB に保存し、時間条件付きの意味検索を実現します。

### インストール

#### 前提条件

- WebGPU 対応の Chrome ブラウザ（Chrome 113 以上）
- WebGPU を利用できるモダンGPU

#### セットアップ

1. リポジトリをクローン:
```bash
git clone <repository-url>
cd tfjs-agentgemma-extension
```

2. 依存関係をインストール:
```bash
pnpm install
```

3. 拡張機能をビルド:
```bash
pnpm run build
```

4. Chrome に読み込み:
   - `chrome://extensions/` を開く
   - 「デベロッパーモード」を有効化
   - 「パッケージ化されていない拡張機能を読み込む」をクリック
   - `dist` フォルダを選択

#### 開発モード

自動再ビルドを有効にした開発時は、次を実行します。

```bash
pnpm run dev
```

### 使い方

1. 拡張機能アイコンをクリックしてサイドパネルを開く
2. 初回利用時はモデルが自動ダウンロードされる（初回のみ）
3. 読み込み後、チャットUIからAIエージェントと対話

### 権限

この拡張機能では次の権限を利用します。

- `sidePanel`: チャットUIの表示
- `activeTab`: 現在のタブ内容へのアクセス
- `storage`: 設定とモデルキャッシュの保存
- `scripting`: コンテンツスクリプトの挿入
- `tabs`: タブURLの取得
- `host_permissions`: 全URL上のページ内容へのアクセス

## 拡張機能アーキテクチャ

この拡張機能は、Transformers.js をブラウザ拡張へ統合するための実用的なアーキテクチャを示しています。  
責務を3つの主要コンポーネントに分離し、それぞれの特性に合わせて最適化しています。

### Background Script: AIエンジン

バックグラウンドの Service Worker が、Transformers.js モデルを集中管理する AI エンジンとして動作します。

**この設計の利点:**

- **モデルの常駐読み込み**: モデルを1回読み込めば、全タブ、サイドパネル、コンテンツスクリプトで共有可能。複数GB級モデルの再読込を回避できます。
- **Service Worker のライフタイム**: ML処理中は Service Worker を維持できるため、数秒かかる推論でも実行しやすくなります。
- **集中処理**: 複数コンポーネントから単一のバックグラウンドへ推論要求を送り、効率的にリソース共有・調停できます。
- **重い処理への適性**: ML推論は高コストですが、バックグラウンドコンテキストはこの種の負荷を扱いやすく、UI応答性を保ちやすいです。

**役割**: モデル読込、推論処理、ツール実行、特徴量抽出

### Side Panel: ユーザーインターフェース

サイドパネルは、エージェントと対話するための継続的なチャットUIを提供します。

**この設計の利点:**

- **状態の持続**: ユーザーが他をクリックすると閉じるポップアップと異なり、サイドパネルは閲覧中も開いたまま会話状態を保持できます。
- **UX向上**: 会話に十分な表示領域を確保し、Webページと並行してアクセスできます。
- **非同期通信**: `chrome.runtime.sendMessage` と `chrome.runtime.onMessage.addListener` により、AIエンジンとノンブロッキングで通信できます。
- **セッション継続性**: ユーザーは質問、タブ移動、会話復帰を繰り返しても文脈を失いにくくなります。

**役割:**
- React 製チャットUIの表示
- ユーザーメッセージのバックグラウンド送信
- エージェント応答とツール実行結果の描画
- 会話履歴の保持

### Content Script: ページ操作

コンテンツスクリプトは Webページ文脈で動作し、DOMへ直接アクセスできます。

**この設計の利点:**

- **DOMアクセス**: 実ページDOMへアクセス・操作できる唯一の拡張コンポーネントで、RAG機能に必須です。
- **適切なセキュリティ境界**: 分離コンテキストで実行されるため、ブラウザの安全性を維持しつつ強力なページ操作を実現できます。
- **ページ単位処理**: タブごとのコンテンツスクリプトが、そのページ専用の抽出・ハイライト処理を担当します。

**役割:**
- 見出し、段落、リストなどの構造化コンテンツ抽出
- エージェント要求に応じた要素ハイライト
- 抽出コンテンツをバックグラウンドへ送信し埋め込み生成に利用
- ハイライトされたコンテンツへのユーザー操作に応答

### 通信フロー

```
ユーザー入力（Side Panel）
    ↓
    chrome.runtime.sendMessage
    ↓
Background Script（AI Agent）
    ↓
    Transformers.js で処理
    ↓
    ツール実行（例: ask_website）
    ↓
    chrome.tabs.sendMessage
    ↓
Content Script（必要時）
    ↓
    ページ内容の抽出・ハイライト
    ↓
    Background へ返却
    ↓
    chrome.runtime.sendMessage
    ↓
Side Panel（応答を表示）
```

### Transformers.js との相性における主な利点

このアーキテクチャは、ブラウザML用途に特に適しています。

1. **リソース効率**: モデルは1回読み込み、推論は中央で実行
2. **UI応答性**: 重いML処理がインターフェースをブロックしにくい
3. **スケーラビリティ**: 複数タブからの要求を同時に処理しやすい
4. **セキュア**: 強力な機能とブラウザのセキュリティモデルを両立
5. **WebGPU高速化**: バックグラウンドでWebGPUを活用した高速推論が可能
